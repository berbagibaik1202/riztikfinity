Panduan Setup Balapan di Roblox Studio

Ikuti 3 langkah mudah berikut untuk menjalankan game balapan di Roblox Anda!

1️⃣ Buat Sirkuit Stadion & Mimbar Komentator VIP (Command Bar)

Di Roblox Studio, buka tab View ➔ centang Command Bar di bawah layar. Tempel (Paste) script ini lalu tekan Enter. Sirkuit stadion oval lengkap dengan gerbang start anti-nyangkut dan Mimbar VIP Komentator (tempat spawn langsung menghadap mobil balap) akan otomatis dibuat!

2️⃣ Pasang Controller Balapan v2.3 (ServerScriptService)

Di Explorer Roblox Studio, klik kanan folder ServerScriptService ➔ Insert Object ➔ Script. Beri nama LiveRaceController, lalu tempel isi script ini ke dalamnya. Sudah dilengkapi grid start anti-nyangkut, tombol kontrol host, dan auto-teleport streamer ke mimbar VIP.

🎥 Pasang Kamera Sinematik & Fokus Gift (StarterPlayerScripts)

Di Explorer Roblox Studio, buka StarterPlayer ➔ klik kanan StarterPlayerScripts ➔ Insert Object ➔ LocalScript. Beri nama LiveRaceCamera, lalu tempel isi script ini. Kamera otomatis menyorot mobil penonton saat gift masuk dan berganti angle dinamis (belakang, depan, drone)!

🏎️ Integrasi Mobil Supercar & Asset RoRacing (Misano, Ferrari, Lambo)

Penonton live TikTok bisa berganti mobil secara real-time via chat: !ferrari, !lambo, !bugatti, !motor, atau otomatis saat kirim Gift Donat 🍩!

💡 Cara Pasang Model 3D Sendiri (Opsional): Buat folder bernama RaceVehicles di ReplicatedStorage. Masukkan model mobil dari RoRacing / Toolbox bernama Ferrari, Lamborghini, Bugatti, Motorcycle. Jika belum ada, sistem akan otomatis memakai model 3D procedural bawaan yang sudah siap pakai!

3️⃣ Aktifkan HTTP Requests di Game Settings

Klik tab Home ➔ Game Settings (Simpan ke Roblox jika diminta) ➔ pilih menu Security ➔ aktifkan centang Allow HTTP Requests ➔ klik Save.

✅ Selesai! Tekan tombol Play / Run (F5) di Roblox Studio. Penonton live TikTok Anda langsung bisa masuk arena balapan!
